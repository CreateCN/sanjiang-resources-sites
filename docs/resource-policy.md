# 资源范围、核验与收录政策

## 1. scope 与 access 是两件事

```ts
type ResourceScope =
  | { type: 'unknown' }
  | { type: 'global' }
  | { type: 'institutions'; institutions: string[] };
```

| 字段 | 回答的问题 | 示例 |
|---|---|---|
| `access` | 打开资源需要什么门槛 | 公开、学生认证、校园网、申请、条件性、未知 |
| `scope` | 资源面向谁 | 未确认、通用、仅限某些机构 |

- `unknown`：维护者尚未确认，前台显示"适用范围待确认，请查阅资格说明"，**不得当成通用**；
- `global`：不面向特定机构，但不等于永久免费、无地区限制或无需个人资格；
- `institutions`：1–20 个机构名，trim、≤100 字、保存时去重；只作说明，不建学校关系表；
- `student-verification` 不会自动变成 `global`；`campus-network` 也不自动对应某校。

## 2. 写入与发布

- 旧数据缺 scope 时读取为 `unknown`，不批量改写草稿、公开快照、修订或核验日期；
- 编辑草稿可修改 scope，公开快照保持不变，直到管理员发布；
- 非法 scope 在保存、导入预检阶段拒绝；
- 历史修订恢复时缺 scope 按 `unknown` 处理，原修订不被改写；
- 导出 v3 为每条资源写明确的 scope；导入 v1/v2 缺字段按 `unknown` 兼容。

## 3. 人工审核

原 12 条资源的逐条审核重点见 [resource-scope-review.md](resource-scope-review.md)。
本轮不批量升级为 `global` 或 `verified`。审核时应：

1. 打开官方说明，确认是否限学校、地区、专业或个人身份；
2. 只有证据充分才从 `unknown` 改为 `global`/`institutions`；
3. 不因"面向大学生"推断某校已订阅或授权；
4. 核验日期只在真正读取官方页面后填写。

## 4. 收录与素材

- 收录有明确用途、可追溯官方来源、能解释费用/资格的公开资源；
- 不收录破解、盗版、共享账号、绕过验证或来源不明的镜像；
- 截图必须有来源、许可与 alt；授权未确认的图片在前台标注并提供下架入口；
- Demo 不使用未确认授权截图，也不伪造当前核验日期；
- 资源方条款、商标、课程/软件许可单独核对，MIT 不覆盖第三方素材。
