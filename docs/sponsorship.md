# 静态赞助位

本页说明赞助位的数据、展示规则、安全边界与运维。它是本地静态广告位，不是自助投放系统。

## 1. 范围

- 只有本地图片或纯文本卡片，固定标注“广告 · 赞助”；
- 不加载第三方脚本、像素、iframe、广告 Cookie 或外部字体；
- 不做点击画像、不把赞助接入资源外跳统计；
- 不提供计费、竞价、自助投放、定向或频控；
- 关闭总开关只停止展示，不删除赞助、图片或历史。

## 2. 数据

赞助保存在 `sponsors` 表，关键字段：

| 字段 | 规则 |
|---|---|
| `title` | 1–100 字纯文本 |
| `body` | 0–300 字纯文本 |
| `sponsor_name` | 1–100 字，公开的赞助方 |
| `media_id` | 可空；引用媒体库图片，删除受 `ON DELETE RESTRICT` 与引用图保护 |
| `image_alt` | 有图片时 1–300 字 |
| `target_url` | 绝对 HTTPS，≤2048；拒绝凭据、本机/内网、保留 IP 与无点主机 |
| `placement` | `home-sidebar` 或 `catalog-promotion` |
| `enabled` | 默认 0；单项开关 |
| `starts_at` / `ends_at` | 可空；UTC ISO 时间；有值时开始早于结束 |
| `version` | 创建为 1，每次更新递增；后台更新与删除必须带版本 |

总开关在 `settings.sponsors`：`{schemaVersion:1,version,enabled}`。缺少该行即关闭；写入使用版本 CAS。

## 3. 展示条件

一条赞助只有在以下条件全部满足时才渲染：

1. 总开关开启；
2. 单项 `enabled=1`；
3. 当前时间满足 `starts_at <= now < ends_at`；空值表示该方向无界；结束时刻为排除边界；
4. 若配置了图片：媒体为 `ready`、未下架、授权已确认、有署名。

同一位置同一时间最多一个启用项。区间按 `[start, end)` 比较，null 表示无界；编辑/创建启用项时在事务内检查重叠，边界相接允许。不同位置互不冲突。

任何条件不满足时，前台不输出容器、不保留占位高度。关闭总开关、空列表、未开始、已过期、图片下架都表现为“没有这一块”。

## 4. 安全边界

- **权限**：所有写操作重新读取当前用户；匿名 401、编辑者/伪造角色 403、停用账户或撤销会话拒绝。旧页面拿到的旧 CSRF 或旧版本不能写入。
- **请求**：沿用现有 `/api/manage/` 的 Origin、CSRF、请求体与限流检查；缺失或错误 Origin 拒绝。
- **输入**：标题/正文/赞助方按纯文本输出，模板转义 HTML；控制字符拒绝。重复表单字段直接 400，不静默取第一条。
- **URL**：只允许 HTTPS；不抓取目标页面，不解析目标 DNS，不加载目标资源。前台只显示 hostname 与静态链接。
- **外链**：`target="_blank"` 且 `rel="sponsored noopener noreferrer"`；没有 `data-outbound`，不进入资源外跳统计。
- **媒体**：上传仍走媒体库的授权、署名、类型与尺寸校验；赞助不能绕过。图片下架或改回未确认后，公开查询立即跳过该条。
- **并发**：更新/删除使用 `version` CAS；总开关使用原始值 CAS；冲突返回 409。
- **审计**：创建、更新、删除、总开关与业务写入同一事务；审计失败整体回滚。
- **CSP**：不新增来源；图片全部同源 `/media/`，没有第三方 SDK。

## 5. 后台操作

入口：管理后台 → 赞助位。

1. 新建赞助，默认停用；填写标题、赞助方、说明、位置、可选媒体与 alt；
2. 时间按北京时间输入，保存时转 UTC；页面会标注时区；
3. 保存后在编辑页查看“当前预览”；
4. 确认文案与图片授权后启用单项；
5. 打开总开关，首页才会出现；
6. 停用单项或关闭总开关立即停止展示，数据保留；
7. 删除会解除图片引用并写审计。

同一位置重叠时会返回冲突并提示现有条目的时间窗，需要先调整时间或停用旧条目。

## 6. 备份、恢复与删除

- 全站备份包含 `sponsors` 表、总开关与媒体对象；业务摘要按表行计算。
- 旧备份恢复后自动获得空赞助表，总开关缺省关闭。
- 赞助图片参与媒体引用图，停用/过期也不自动解除；只有删除赞助或换图后才允许彻底删除媒体。
- 普通内容 JSON 导入/导出不包含赞助，也不提供广告导入。

## 7. 不做的事

- 不接第三方广告 SDK、像素、受众定向或再营销；
- 不做点击/曝光画像，不把赞助点击混入资源统计；
- 不做自助投放、在线支付、发票或按点击计费；
- 不自动抓取赞助方页面或图片；
- 不在赞助位执行内联脚本或自定义 HTML。

## 8. 排查

| 现象 | 检查 |
|---|---|
| 后台有条目但前台没有 | 总开关、单项启用、当前时间窗、图片是否 ready/授权/署名 |
| 保存返回 409 | 单项版本过期，或同位置时间重叠 |
| 保存返回 400 | URL 非 HTTPS/私网、时间为空或时区错误、有图无 alt、媒体不可用 |
| 图片 404 | 媒体已下架/删除；赞助会整条停止展示 |
| 恢复后没有赞助 | 备份是否来自含 012 迁移的版本；旧备份按空表与关闭处理 |
| 关闭后仍看到 | 反向代理/CDN 缓存；页面本身不缓存赞助查询 |
