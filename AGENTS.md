## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `CreateCN/sanjiang-resources-sites`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five state labels, each named after its canonical role: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` plus `docs/adr/`. See `docs/agents/domain.md`.
